# 🚀 Quick Guide: Free AI API Platforms

A cheat sheet of platforms offering free API access to AI models, categorized by their access model.

---

## 📅 1. Permanent Free Tiers (Rate-Limited)
These platforms provide permanent access that never expires. Usage is regulated by daily or minute-based rate limits.

| Platform | Best Free Models Available | Core Free Limits | Essential Catch / Details |
| :--- | :--- | :--- | :--- |
| **[Google AI Studio](https://google.com)** | Gemini 3 Flash, Gemini 3.1 Flash-Lite | 1,500 requests / day | ⚠️ Google trains its models on free-tier prompts. |
| **[GroqCloud](https://groq.com)** | Llama 3.3 70B, Gemma 2 9B | ~14,400 requests / day (varies by model) | Insanely fast LPU inference. No credit card needed. |
| **[OpenRouter](https://openrouter.ai)** | DeepSeek R1/V3, Qwen 2.5, Mistral | Varies (over 50+ models are 100% free) | Aggregator; lets you swap models with one API key. |
| **[Mistral AI](https://mistral.ai)** | Mistral Large, Codestral, Pixtral | Rate-limited "Experiment" tier | Excellent for code generation and European multilingual tasks. |
| **[Cohere](https://cohere.com)** | Command R+, Embed, Rerank | 1,000 requests / month | Built with a permanent "Trial Key" for prototyping. |
| **[Cerebras](https://cerebras.ai)** | Llama 3.3 70B, Llama 8B | Generous daily rate limits | Hardware competitor to Groq; built for raw speed. |

## 🎁 2. Promotional Sign-Up Credits (One-Time / Expiring)
These platforms do not offer a permanent free tier. Instead, they give you a free starting dollar balance when you register a new account.

* **[xAI Console (Grok)](https://x.ai):** 
  * **\$25 free** on signup.
  * Earn up to **\$150/month recurring** if you opt into their data-sharing evaluation program.
* **[Together AI](https://together.ai):** 
  * **\$25 to \$100 free** credit balance upon registration.
  * Access to a massive catalog of open-source image, language, and audio models.
* **[OpenAI API](https://openai.com):** 
  * **\$5 free** token credit given to newly verified phone numbers.
  * Good for a quick test of GPT-4o or GPT-4o-mini.
* **[Anthropic Console](https://anthropic.com):** 
  * **\$5 free** token credit upon phone verification.
  * Used to test the Claude 3.5/3.7 Sonnet or Haiku model families.
* **[Hugging Face Inference](https://huggingface.co):** 
  * **Free low-tier** serverless architecture.
  * Mainly for testing and evaluating thousands of community-uploaded models.
